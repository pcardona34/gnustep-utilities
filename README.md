# gnustep-utilities
A collection of GNUstep Utilities to be used  with AGNoStep Apps Manager.

## Goal

This module is useful with 
[agnostep-apps-manager](../../../agnostep-apps-manager).
It allows to retrieve the source of most of the known 
GNUstep Utilities like Affiche... 
and then to build and install them into a GNUstep Desktop.

> [!NOTE] This is a work in progress, as we are replacing 
> previous `AgnostepManager.app` with this new module method.
